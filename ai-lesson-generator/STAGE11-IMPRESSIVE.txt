STAGE 11 — IMPRESSIVE EDITION
=============================

WHAT YOU GET
1. Live interactive lecture (human avatar + animated diagrams synced to speech) — already excellent from Stage 10.
2. QUIZZES — every new lesson includes 4–6 multiple-choice questions with explanations and scoring.
3. ASK THE LECTURER — floating panel. Type a question mid-lesson; the AI answers in the lecturer’s voice, the avatar speaks and gestures, then you can continue.
4. Mode tabs to switch between Lecture and Quiz.
5. Polished UI for the new features.

VIDEO NOTE
True AI video (photoreal talking-head MP4) needs external video APIs (Runway, Veo, etc.) and is not practical for a local free stack. This system is intentionally an interactive live lecture that is more powerful than a static video: you can pause, jump, ask questions, and take quizzes. Presentation / fullscreen browser mode already feels like a teaching video.

HOW TO RUN (same as before)
1. backend/.env  → put GROQ_API_KEY / GEMINI_API_KEY / TAVILY_API_KEY
2. backend:  python -m venv .venv && source .venv/bin/activate (or Windows equivalent)
   pip install -r requirements.txt
   uvicorn app.main:app --reload
3. frontend: npm install && npm run dev
4. Open the Vite URL (usually http://localhost:5173)

Generate a NEW lesson to get quizzes. Older saved JSON lessons still load (quizzes array will be empty).

NEW API
POST /api/lessons/ask
Body: { "topic", "question", "lesson_title?", "section_heading?", "section_summary?" }
Returns: { "answer", "avatar_action" }


VIDEO DOWNLOAD (added)
- Click "Record video" while viewing a lesson.
- Browser will ask you to share this tab (choose the current tab + share audio if offered).
- Play the lecture. When finished click "Stop & download".
- A .webm video file downloads (Chrome / Edge / Firefox). You can convert to MP4 with free tools if needed.
- This records the real animated lecture (avatar + diagrams + speech) — no external video API required.
